# 输出目录结构说明

本目录是项目的统一输出目录，所有爬虫数据、策略研究报告和其他输出文件都存放在这里。

## 📁 目录结构

```
输出/
├── 爬虫/                    # 爬虫相关输出
│   ├── 雪球爬虫/            # 雪球爬虫的输出
│   │   ├── 原始数据/        # 抓取的原始JSON数据（双轨制：原始存储）
│   │   ├── 分类整理/        # 经过分类整理的报告（双轨制：知识输出）
│   │   ├── 投资知识库/      # 构建的投资知识库文档
│   │   └── 日报/           # 每日生成的摘要报告
│   └── 其他爬虫/           # 其他爬虫的输出（预留）
│
├── 策略研究/               # 投资策略研究输出
│   ├── 单人/              # 单人策略分析报告
│   ├── 每年/              # 年度策略分析
│   ├── 每月/              # 月度策略分析
│   └── 回测结果/          # 策略回测的结果文件和图表
│
└── 其他/                   # 其他类型的输出文件
```

## 🎯 设计原则

### 1. 统一输出管理
- 所有输出文件集中到 `输出/` 目录
- 按功能模块分类（爬虫、策略研究等）
- 避免分散在多个位置

### 2. 数据双轨制（符合用户偏好）
根据用户的**数据抓取与输出双轨制偏好**：
- **原始数据层**：保存抓取的原始JSON数据
- **知识输出层**：经过分类、整理、分析后的可利用文档

### 3. 代码解耦架构
遵循**代码解耦与数据处理架构原则**：
- 爬虫只负责数据抓取和基础存储
- 独立的后处理脚本进行数据分类和分析
- 报告生成作为独立环节

1. **新增爬虫输出**：统一放到 `输出/爬虫/[爬虫名称]/` 下
2. **策略研究报告**：放到 `输出/策略研究/` 对应子目录
3. **定期清理**：删除测试文件和临时文件
4. **保持双轨制**：同时维护原始数据和知识输出
